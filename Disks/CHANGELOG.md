# Changelog

## [1.1.0] - 2026-10-08
- Added an info button to the detail view that shows a disk's format, whether it is internal or external, whether it is read-only, and the size of each partition of its physical disk with a bar for each.

## [1.0.0] - 2026-10-04

- Added a shelf widget that lists every mounted disk with its icon and name, with Open and Eject buttons on each row.
- Added a progress state to Eject, and a message that gives the reason when a disk can't be ejected.
- Added a detail view that shows a disk's used space as a bar and a figure when you click it.
- Added a paired view that lists the disks by name.
