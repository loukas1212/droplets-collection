# Droplets Collection

Welcome to Droplets Collection, a collection of Droplets (extensions) for [Droppy](https://getdroppy.app), built with [DroppyKit](https://getdroppy.app/docs/droppykit).

Every folder inside this repository is a Droplet. You can find information about each Droplet in the `README.md` file inside its folder.

To use a Droplet, you need to build it using [DroppyKit](https://getdroppy.app/docs/droppykit), and then install it manually inside Droppy.

Building a Droplet requires Xcode 26 and DroppyKit 1.20 or later. To build a Droplet, simply go inside the Droplet folder and use these commands:

```bash
droppykit run
droppykit validate
droppykit build
```

If you don't know how to install DroppyKit, please use [this link](https://getdroppy.app/docs/droppykit/add-spm).

If you see any problems or bugs, feel free to open an issue !
